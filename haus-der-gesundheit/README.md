# Haus der Gesundheit Website

## Projektübersicht
Die Website "Haus der Gesundheit" ist eine moderne, professionelle Plattform für eine ernährungstherapeutische Praxis, die auch Bewegungstherapie anbietet. Die Website ist minimalistisch und übersichtlich gestaltet, um eine optimale Benutzererfahrung zu gewährleisten.

## Projektstruktur
Die Projektstruktur ist wie folgt:

```
haus-der-gesundheit
├── index.html          # Hauptseite der Website
├── ueber-mich.html     # Informationen über die Praxis und das Team
├── leistungen.html     # Übersicht der angebotenen Leistungen
├── kontakt.html        # Kontaktformular und Informationen
├── praxis.html         # Beschreibung der Praxisumgebung
├── css
│   └── style.css       # CSS-Stile für die Website
├── js
│   └── script.js       # JavaScript für interaktive Funktionen
└── README.md           # Dokumentation des Projekts
```

## Dateienbeschreibung

- **index.html**: Die Hauptseite der Website, die den Hero-Bereich, die Navigation und Call-to-Action-Buttons enthält.
- **ueber-mich.html**: Informationen über die Praxis, die Fachkräfte und deren Qualifikationen.
- **leistungen.html**: Detaillierte Beschreibung der angebotenen Dienstleistungen, einschließlich Ernährungstherapie und Bewegungstherapie.
- **kontakt.html**: Kontaktformular für Anfragen sowie Kontaktdaten und Standort der Praxis.
- **praxis.html**: Informationen über die Praxisumgebung, einschließlich Bilder und Beschreibungen der Einrichtungen.
- **css/style.css**: Enthält die Stile für die Website, einschließlich Layout, Farben und responsive Design-Elemente.
- **js/script.js**: JavaScript für interaktive Funktionen wie sanftes Scrollen, Hover-Effekte und Formularvalidierung.
- **README.md**: Dokumentation des Projekts, die Anweisungen zur Einrichtung, Funktionen und weitere relevante Informationen enthält.

## Einrichtung
Um die Website lokal zu betreiben, öffnen Sie die `index.html`-Datei in einem Webbrowser. Es sind keine zusätzlichen Abhängigkeiten oder ein Backend erforderlich.
